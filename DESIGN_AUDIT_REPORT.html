三、核心发现（已量化验证）

3.1 动效降级（reduced-motion）缺口 — 最高优先级

app/globals.css 第 277–284 行存在 reduced-motion 媒体查询，但仅禁用了 .animate-marquee 与 .cta-sheen::after 两个类。全站实际使用的动效远不止于此：

动效来源是否受 reduced-motion 保护量（app 下）
components/reveal.tsx（滚动入场）已保护（JS 检测 matchMedia）封装复用
Tailwind animate-pulse / animate-spin未保护40+ 处
Framer Motion motion.div / whileHover / animate未保护（JS 驱动，CSS 媒体查询无法拦截）graph-rag 14 处等

典型高危：graph-rag 的移动端循环浮动箭头（animate={{y:[0,4,0]}} repeat:Infinity）、各 demo 的持续 animate-pulse 状态徽章、function-calling 37 处密集脉冲。前庭敏感用户在系统开启「减少动态效果」后仍会看到持续运动。

3.2 颜色硬编码与强调色预算漂移

项目使用 shadcn 语义 token（primary / secondary / muted / foreground / border）。但多个 demo 直接写入固定色值，绕过主题 token：

  • text-blue-500 / bg-blue-500 / cyan-500 / teal-500 / emerald-500（graph-rag 流程状态）
  • purple-500 / rose-400 / amber-500（function-calling、context-engineering 状态点）
  • dashboard 四个 stat 图标分别用 green / primary / chart-2 / chart-3 四种色相

风险：在暗色主题下，这些固定色与背景对比度未经统一校验，且偏离品牌主色（primary 紫），造成「每页一种配色」的视觉碎片化。ui-craft 强调单一强调色 + 语义色（绿=完成/成功，neutral=待定）的预算纪律。

3.3 对比度风险（小字 + 透明度降灰）

多处 text-[9px]~[11px] 小字叠加 /40、/60、/70 透明度降灰（如 graph-rag 第 378/389/417/485 行），在暗色背景上易低于 WCAG AA 正文 4.5:1 阈值。属高概率不达标项，建议抽样用对比度工具复核。

3.4 可访问性语义缺口

  • 动态结果区（graph-rag 的 result 卡片）与流水线状态变化无 aria-live，屏幕阅读器用户收不到「检索完成」通知。
  • auth 表单无 autocomplete="email"，无可见错误态（仅有 placeholder 提示）。
  • 大数字（dashboard 统计、graph-rag 计数）缺 tabular-nums，数字宽度跳动。

五、修复方案与代码示例

5.1 扩展 globals.css 的 reduced-motion（覆盖 Tailwind 内置动画）

/* app/globals.css — 扩展 reduced-motion 保护 */
@media (prefers-reduced-motion: reduce) {
  .animate-marquee { animation: none; }
  .cta-sheen::after { display: none; }
  /* 新增：禁用 Tailwind 内置无限/脉冲动画 */
  .animate-pulse,
  .animate-spin,
  .animate-bounce,
  .animate-ping { animation: none !important; }
  * { scroll-behavior: auto !important; }
}

这能一次性覆盖 40+ 处 Tailwind 动画。但无法拦截 Framer Motion 的 JS 驱动动画——需配合 5.2。

5.2 Framer Motion 用 useReducedMotion 拦截

// 在 graph-rag 等使用 motion.* 的组件中
import { useReducedMotion } from "motion/react";

const reduce = useReducedMotion();
// 循环中浮动箭头：reduced 时静态显示
<motion.div
  animate={reduce ? {} : (isCurrent ? { y: [0, 4, 0] } : {})}
  transition={{ repeat: Infinity, duration: 1.2 }}
/>
// whileHover 同理：reduce 时关闭位移
whileHover={reduce ? {} : { y: isPending ? 0 : -2 }}

5.3 用语义 token 替换硬编码色

// 之前（graph-rag 流程状态）
className="bg-blue-500/10 text-blue-500 ..."   // 硬编码
// 之后：用 primary（进行中）+ emerald（完成）+ muted（待定）
className="bg-primary/10 text-primary ..."      // 进行中
className="bg-emerald-500/10 text-emerald-500"   // 完成（语义绿，保留）
className="bg-muted text-muted-foreground"       // 待定

原则：品牌强调色统一用 primary；「完成 / 成功」语义允许保留 emerald（语义色，非装饰）；删除 blue/cyan/teal/purple/rose/amber 等纯装饰色相。

5.4 为动态结果区加 aria-live

{/* graph-rag result 卡片 */}
<div aria-live="polite" aria-atomic="true">
  {result && ( /* 检索结果内容 */ )}
</div>
