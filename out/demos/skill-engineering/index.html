Anthropic Skills 核心原则
  • 专业化指导： 使用清晰的指令教导 Claude 完成特定任务和流程
  • Markdown 格式： 使用 YAML 元数据 + Markdown 内容的简洁格式定义技能
  • 具体示例： 通过示例和最佳实践帮助 Claude 理解和应用技能
  • 持续优化： 基于实际效果反馈，不断完善和更新技能指令
