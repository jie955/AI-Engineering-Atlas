Loop Engineering

设计自我驱动的 Agent 循环 - 6 大组件 + 循环流程 + 风险边界

2026 前沿
你不再 prompt Agent，而是设计 prompt Agent 的循环
"我不再 prompt Claude 了。我运行循环去 prompt Claude 并决定下一步做什么。我的工作是写循环。"
— Boris Cherny，Anthropic Claude Code 负责人
Loop Engineering 位于 Harness Engineering 之上：Harness 是单个 Agent 运行的环境，而 Loop 让这个环境定时运行、自我派发任务、自我喂养。

关键提示
自动化让循环成为真正的「循环」，而不是只跑一次的任务。让 automation 调用 skill 而非粘贴大段指令
为什么 Loop 设计比 Prompt 工程更难
  • 杠杆点移动了：Cherny 的观点不是工作变简单了，而是杠杆点从「写好 prompt」移到了「设计好循环」
  • 同一个循环，相反的结果：两个人搭出完全相同的循环，可以得到完全相反的结果。一个用它在深刻理解的工作上跑得更快，另一个用它彻底逃避理解工作。循环不知道区别，你知道
  • 保持平衡：去搭你的循环，但别忘了直接 prompt Agent 同样有效。关键是找到正确的平衡
